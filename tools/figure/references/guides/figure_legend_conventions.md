# 图注写作规范

在编写或审核图注文本时使用本参考。它补充 `design_theory.md`（视觉/布局），
本文件覆盖图注的*文字*部分。

## 图注结构 — 固定骨架

1. **`图 N | ` + 加粗名词短语总题**，命名整张图。常用开头：*四种优化算法的对比*、
   *灵敏度分析结果*、*预测性能评估*。标题末尾不加句号。
2. **`a / b / c …` 面板**，每个用现在时、电报式描述，通常省略主语：
   *"a 粒子群算法在测试函数 F1 上的收敛过程。b 六种算法在三个指标上的对比。"*
3. **统计写进图注**：样本量 `n=`、误差类型、检验方法 —
   *"均值 ± 95% CI (n = 50) … 单因素 ANOVA 配合 Tukey 校正。"*
4. **数据可用性套语**在末尾：*"源数据以 CSV 文件提供。"*

## 时态

- 视觉事实用**现在时** — *"显示为蓝色柱"*、*"展示了…的关系"*。
- 制作方法用**过去时** — *"通过…计算"*、*"采用…方法"*。

## 自足规则

图注必须脱离正文可读。将颜色/形状映射、样本量、关键数值（单位、算法参数）
写进图注本身 — *"测试函数 F1 (维度 D=30, 求解次数 10⁵)。蓝色实线表示 PSO 算法，
橙色虚线表示 GA 算法。"*

## 进阶：结论收束句

图注最后一句可以推进论证而不只是描述 —
*"…表明差分进化算法在该问题上具有最优的收敛精度和稳定性。"*
谨慎使用，仅在面板确实支撑该推断时使用。

## 数学建模图注要点

- **三类图体系**：原始数据图注侧重数据描述，过程图注侧重方法行为，
  结果图注侧重结论支撑。
- **误差交代**：图注必须写清误差类型（SD / SEM / 95% CI / IQR）、
  样本量 n、检验方法、校正方式和显著性符号定义。
- **复现信息**：关键参数（种群规模、迭代次数、学习率等）应在图注或正文中交代。
- **中文图注**：结构铁律 — `图 N | 加粗名词短语总题` → `a/b/c` 现在时电报式分面 →
  统计 (n、误差、检验) 写进图注 → 数据可用性套语。

## 长度限制

- Nature 风格图注 ≤ 300 词。
- 中文数学建模论文图注通常 100-200 字。
- `图 N |` 标题行简短；数字和结果放在面板描述和统计中，不放在标题行。

# 绘图资产适配

在复用打包示例、预览图或用户提供的绘图脚本时使用本参考。将示例视为视觉和结构起点，而非脚本与新数据兼容的证据。

## 选择复用层级

编辑前将每个候选分配到四个层级之一：

| 层级 | 使用场景 | 允许的变更 |
|------|---------|-----------|
| 精确复用 | 科学含义、数据形状、变换和后端全部匹配 | 仅输入路径、标签和输出前缀 |
| 结构适配 | 科学含义和维度匹配，但字段名或分组标签不同 | 显式字段映射+文档化变换守卫 |
| 仅样式继承 | 图族有用但数据结构或统计量不同 | 仅调色板、字体、间距、标记、图例和标注约定 |
| 重新构建 | 候选回答不同问题或需替换其统计逻辑 | 不要强行套模板；直接实现已确认的图表契约 |

不要仅因为脚本能渲染其打包示例就将其标记为生产就绪。

## 映射前检查

1. 有配套预览图时先打开。
2. 说明候选实际显示的内容：维度、标记类型、分组、统计量、不确定性、变换和标注。
3. 说明所请求面板必须回答的问题。
4. 含义不同时拒绝结构复用。2D 联合密度图不是多个 1D 边际密度的可复用实现，基准柱状图也不是小样本统计对比的有效模板。

## 映射数据契约

修改代码前写出显式映射：

```text
模板字段 -> 用户字段 -> 角色 -> 单位 -> 允许值
分组字段 -> 用户字段 -> 分类顺序
重复单元 -> 源行/图像 -> 技术或生物学重复
不确定性 -> 源字段或计算 -> 定义
```

有歧义的映射与用户确认。永远不要为了方便而静默选择列。保持标识符与测量值分离，除非有科学依据的排序，否则保持请求的分类顺序。

## 守卫变换

对每个继承的变换检查新数据：

- 对数轴和对数变换要求严格正值，除非有经声明的符号对数或伪计数方法且科学合理。
- 比率和归一化值要求分母有限且定义了零分母策略。
- 平方根变换要求非负输入。
- Min-max 缩放要求非常量有限范围。
- 分箱和密度估计要求足够多的不同观测值；记录分箱或带宽选择。
- 相关性、PCA、聚类和统计标注要求显式缺失值处理和适当的重复单元。

守卫失败时，仅在科学含义仍有效的情况下更改变换并记录。否则使用仅样式继承或重新构建。

## 保留来源

- 默认使用所有提供的观测值和请求的变量。
- 不要为了美观或渲染速度而下采样。使用光栅化、hexbin/密度标记、透明点、带声明规则的聚合或后端原生大数据渲染。
- 如果分析需要筛选，记录精确谓词和筛选前行/列/重复/图像计数。
- 用户明确请求采样时，记录方法、样本量、种子以及采样是否改变任何推断性声明。
- 永远不要在生产交付物中留模拟值。在显式 demo 标志或单独示例文件后隔离演示。

## 适配时不抹去来源

编辑前将候选复制到任务工作空间。保持源资产不变。保留许可证和归属信息，但在生成的图表、图例、论文文本或面向用户的报告中不暴露私有本地路径或私有模板标识符。

在内部 QA 笔记中记录复用层级和来源类别。

## 验证与交付

1. 使用所选后端和代表性真实输入运行适配脚本。
2. 运行 `python scripts/validate_figure.py path/to/script.py`。
3. 静态验证仅作为预检；无法确认统计正确性或视觉质量。
4. 检查 SVG/PDF 文本可编辑性、光栅分辨率、裁剪、重叠、颜色可访问性和最终物理尺寸下的可读性。
5. 在 QA 笔记中包含字段映射、排除项、变换更改和剩余注意事项。
